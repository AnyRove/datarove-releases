DataRove は、定期バックアップと同期を内蔵したデスクトップ向けデータベースクライアントです。パソコン上で（アプリまたはバックグラウンドサービスとして）動作し、スマホは LAN 直結またはリレー経由で接続します。通信はエンドツーエンドで暗号化され、データベースのパスワードがパソコンの外に出ることはありません。

**対応データベース：** MySQL · MariaDB · PostgreSQL · SQLite · SQL Server · MongoDB · Redis（SSH トンネル・TLS 対応）

> **ステータス：** 1.0.0。インストーラーは [Releases](../../releases) ページからダウンロードできます。インストール後はアプリが自動で更新されます。新しいバージョンの通知を受け取るにはこのリポジトリを Watch してください。変更履歴は [CHANGELOG](CHANGELOG.md)。

## 機能

### データの閲覧と編集
- 仮想スクロールの高速グリッドで、フィルター・並べ替え・ページングに対応。セルをその場で編集するほか、行全体をフォームで開き、列の型（真偽値、列挙型、日付、JSON、NULL / 既定値）に合った入力欄で編集できます。
- 外部キー列では、参照先のテーブルを検索して行を選べます。
- 保存前に実行される SQL をプレビューできます。変更はすべて 1 つのトランザクションでコミットされ、エラー時はまとめてロールバックされます。削除や本番接続では事前に確認します。
- CSV / TSV / JSON / SQL / Markdown 形式でのコピー、ファイルへのエクスポート、CSV / JSON のインポート。

![データグリッド](docs/images/data.png)

### クエリを書く
- 文脈に応じた SQL 補完：`FROM` / `JOIN` の後はテーブル、`エイリアス.` の後は列、`INSERT` の列リスト、シグネチャ付きの関数、文のテンプレート。
- テーブルや列にマウスを合わせると、構造・型・コメントを表示。存在しないテーブル名や `エイリアス.列`、`WHERE` のない `DELETE` / `UPDATE` は実行前に下線で警告します。
- 主キーを含む単一テーブルの `SELECT` 結果は、そのまま編集して保存できます。
- MongoDB のシェル構文（`db.users.find({...})`）と Redis のコマンドラインにも補完付きで対応。

![クエリエディター](docs/images/query.png)

### スキーマを把握する
- データベース → テーブル / ビュー / コレクション → 列、インデックス、外部キー、トリガー、DDL、行数、サイズ。
- ER 図、2 つのデータベースのスキーマ比較と移行 SQL の生成、Redis キーブラウザー、サーバーモニター（接続数、QPS、スロークエリ）。

![ER 図](docs/images/er.png)

### インポートとエクスポート
- テーブル全体や絞り込み結果を CSV、TSV、JSON、JSON Lines、SQL `INSERT`、Markdown でエクスポート。CSV / TSV / JSON / JSON Lines をインポート（UTF-8 と GBK を自動判別）。
- 大きな転送はパソコンのバックグラウンドで実行され、進捗表示とキャンセルに対応。小さな単位で送るので、接続が切れても途中から再開します。
- インポートは 1 つのトランザクションで実行。1 行でも失敗すれば何も書き込まず、失敗した行を示します。

### 信頼できるバックアップ
- ネイティブツール（mysqldump / pg_dump / mongodump）または内蔵エクスポーターでファイルにバックアップ。gzip 圧縮、AES-256-GCM 暗号化、直近 N 件または N 日分を保持。
- 新しいバックアップは書き込み直後に読み戻して検証（チェックサム、復号、解析）するので、壊れたファイルはその夜のうちに見つかります。
- 別のデータベースへの同期：全件置換、全削除後に投入、追記、主キーによる upsert、ウォーターマーク列（`updated_at`、自動採番 ID など）による**差分**同期。
- スケジュール：N 分ごと、毎日、毎週、毎月、cron。実行されなかった分は起動時に実行。デスクトップ通知と Webhook。どのバックアップもワンクリックで任意の接続に復元できます。
- 同期はデータベースの種類をまたいでも可能（例：PostgreSQL → MySQL）。各テーブルは完全に書き込まれるか、まったく変わらないかのどちらかで、確定前に行数を照合します。一時的なエラーは自動で再試行し、それでも失敗した場合は**失敗した部分だけを再試行**できます。足りないツール（pg_dump など）はアプリからワンクリックでインストールできます。

![バックアップ](docs/images/backups.png)

### 操作ミスを取り消す
- 「本番」に設定した接続では、`UPDATE`、`DELETE`、`DROP`、`TRUNCATE`、グリッド編集、上書きインポート、同期、リストアの前に、影響を受けるテーブルを DataRove が保存します。
- あとからワンクリックで取り消し：差分のある行だけを 1 つのトランザクションで元に戻します。スナップショットはパソコン上に暗号化して保存されます。

### スマホから安全に
- スマホでも同じ画面を使えます。QR コードを読み取ってペアリングするだけで、アカウント登録は不要です。
- スマホごとに権限（読み取り専用、読み書き、管理）を設定でき、いつでも変更・削除できます。一時的な権限付与は期限が来ると自動で戻り、操作履歴で各スマホの操作を確認できます。
- 同じ Wi-Fi ではパソコンに直結し、外出先では暗号文を中継するだけのリレーを経由します。

<p align="center"><img src="docs/images/phone-data.png" width="300" alt="スマホで動く DataRove"></p>

### デスクトップ
システムトレイに常駐し、ログイン時に起動します。バックグラウンドサービス（launchd / systemd / Windows タスク スケジューラ）として自分をインストールできるので、ウィンドウを閉じても定期バックアップは動き続けます。テーマ 10 種、ライト / ダーク、UI 言語 15 種類。

## セキュリティの要点

- 保存したパスワードはパソコン上でローカルのマスターキーにより暗号化されます。画面やペアリング済みのスマホには `••••` しか表示されません。
- QR コードでのペアリングには 256 bit の秘密鍵を使い、手入力する短いコードは scrypt で強化しています。双方が互いの鍵を検証するため、リレーが自分の端末を紛れ込ませることはできません。
- 各セッションは X25519 + ChaCha20-Poly1305 で、毎回新しい一時鍵を使います（前方秘匿性）。改ざん・再送・順序入れ替えされたフレームは拒否され、ダウングレード攻撃も拒否します。
- インターネット上のリレーには `wss://` が必須です。リレーは自分で運用でき、LAN 内だけでペアリングすることもできます。
- DataRove の外に関わる操作はパソコン上でのみ可能です：ツールのパス、ファイルの閲覧、SQLite ファイルへのアクセス、変更された接続先への保存済みパスワードの送信。

脆弱性の報告は [SECURITY.md](SECURITY.md) をご覧ください。

## インストール

[最新リリース](../../releases/latest) からお使いのシステム用のファイルをダウンロードしてください。各リリースの `SHA256SUMS.txt` に SHA-256 チェックサムがあります。インストーラーはまだ Apple / Microsoft の開発者証明書で署名されていないため、最初に一度確認が表示されます。

- **macOS**：`.dmg` を開き、DataRove を「アプリケーション」にドラッグします。初回起動時に確認できないと表示されたら、「システム設定 → プライバシーとセキュリティ」を開き、下の方にある「このまま開く」をクリックします。「壊れている」と表示された場合は、ターミナルで `xattr -cr /Applications/DataRove.app` を実行してから開いてください。
- **Windows**：`.exe` を実行します。SmartScreen が表示されたら「詳細情報 → 実行」をクリックします。
- **Linux**：`.AppImage` に実行権限を付けて実行するか、`.deb` をインストールします。
- **Android**：`.apk` を開き、ブラウザーまたはファイルマネージャーからのインストールを許可します。アプリはパソコンの DataRove とペアリングして使うほか、スマホ直接接続モードで自分でデータベースに接続することもできます（初回に DataRove アカウントでスマホを有効化します）。

その後、アプリでメールアドレスでサインインし、パソコンを有効化します。DataRove は無料で、支払い情報は不要です。
